# Sobre o projeto

Este repositório contém os arquivos-fonte de um **resource pack para Minecraft: Java Edition** que adiciona uma tradução completa do **End Poem** para o português brasileiro (PT-BR).

O End Poem é o texto exibido ao jogador após a derrota do Ender Dragon e a entrada no portal de saída do End.

# Estrutura

A estrutura do repositório corresponde à estrutura interna do resource pack.

O arquivo end.txt contém o texto traduzido do End Poem.

# Tradução

O End Poem foi escrito por **Julian Gough**, que é o autor do poema original e recebe os devidos créditos pela obra.

A tradução para o português brasileiro utilizada como base neste projeto foi disponibilizada pela **Fuzzy Escola de Ciência e Tecnologia**:

**https://fuzzy.tec.br/end-poem**

O projeto consiste na implementação dessa tradução como um resource pack para Minecraft: Java Edition.

# Modrinth

A versão distribuída e pronta para instalação pode ser encontrada no Modrinth:

**https://modrinth.com/resourcepack/traduo-do-end-poem-em-pt-br-java-apenas**

# Compatibilidade

Este projeto é destinado exclusivamente ao **Minecraft: Java Edition**.

Consulte a página do projeto no Modrinth para obter informações sobre as versões atualmente suportadas.
